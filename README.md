# MuseFlow (灵眸流)

> **非破坏性本地媒体管理 × 算法推荐流式消费 × AI 智能分类中枢**
> 
> 让散落在硬盘深处的旅游照片、Vlog 工程、系列视频与音乐，以“小红书 / Bilibili / 抖音”般的私人算法流重新焕发光彩。

---

## 🌟 核心理念与痛点解决

市面上的工具往往将“**资产管理（DAM）**”与“**流媒体消费（Streaming）**”割裂：
- **Eagle / Billfish**：擅长打标管理，但打开像在上班，缺乏被算法推荐喂饭、沉浸式刷内容的体验。
- **Plex / Jellyfin / Immich**：擅长流媒体，但对复杂的“工程包”（如一个文件夹内的 `mp4 + wav + srt`）处理死板，缺少跨维度的虚拟超集和开放算法插件。

**MuseFlow** 创造性地融合两者：
1. **底层物理非破坏**：原生索引本地磁盘目录，无需强行导入专有库，随时随地双击调用系统默认程序打开。
2. **复合原子单元（Asset Unit）**：智能识别“根元素”。单个照片是原子，但一个含有 `视频 + 音频轨 + 字幕` 的文件夹也是一个不可再分的消费原子。
3. **双态视图（Dual Mode）**：
   - **管理态（Workplace）**：树状目录、文件夹管理、批量归集、AI 辅助整理接口。
   - **消费态（Immersion Feed）**：小红书式瀑布流、B 站式卡片流、抖音式上下滑视频流、专业音乐播放。
4. **可插拔推荐系统（Pluggable Recommender）**：内置停留时长、点击频次、评分反馈等数据埋点，支持规则推荐、统计推荐与 AI Agent 智能推荐插件。
5. **多维虚拟超集（Supersets）**：文件物理位置不动，但可以跨文件夹自由构建“某人的全部合影”、“2024旅行足迹”等任意超集。

## 🏗️ 核心数据架构

```
┌────────────────────────────────────────────────────────┐
│               虚拟超集 (Virtual Superset)               │
│        (例如: "所有包含好友A的内容", "历年海滩精选")        │
└───────────────────────────┬────────────────────────────┘
                            │ 虚拟引用 / 动态查询
┌───────────────────────────▼────────────────────────────┐
│                    系列 (Collection)                    │
│             (例如: 2024川西大环线, 某个短片工程)          │
└───────────────────────────┬────────────────────────────┘
                            │ 包含 (1:N)
┌───────────────────────────▼────────────────────────────┐
│              原子消费单元 (Asset Unit / 根元素)          │
│   (例如: 独立图片, 独立音乐, 或 mp4+wav+srt 复合包)      │
└───────────────────────────┬────────────────────────────┘
                            │ 映射 (1:N)
┌───────────────────────────▼────────────────────────────┐
│                  物理磁盘文件 (Raw Files)               │
│                  D:/Photos/2024/..., etc.              │
└────────────────────────────────────────────────────────┘
```

## 🗺️ 演进路线图 (Roadmap)

- [ ] **Phase 1: 基础底座与双态交互 (MVP)**
  - [ ] 物理目录扫描与文件监听（非破坏性索引）
  - [ ] 复合原子单元检测（智能识别 `mp4+srt+wav` 视频包、图片集）
  - [ ] 本地双态 UI：管理态（文件树/文件管理器）+ 消费态（卡片流/小红书瀑布流）
  - [ ] 多模态内嵌播放器（带字幕视频播放器、高保真音频播放器、灯箱相册）
  - [ ] 外部快速唤起（支持一键在系统资源管理器打开、用系统默认软件打开）

- [ ] **Phase 2: 行为遥测与可插拔推荐引擎**
  - [ ] 用户行为埋点（停留时长保护阈值、评分、点击、点赞）
  - [ ] 推荐引擎插件接口（Rule-based / Statistics / AI Embedding）
  - [ ] 沉浸式流媒体体验（抖音式上下滑动快速刷视频/Vlog）
  - [ ] 封面自适应与智能裁剪

- [ ] **Phase 3: 虚拟超集与 AI 智能中枢**
  - [ ] 跨物理目录的“虚拟超集”构建与动态过滤
  - [ ] 开放 AI 整理 API（自动打标、聚类建议、散落文件智能归集）
  - [ ] “记忆唤醒”推荐（“三年前的今天”、“很久未回顾的宝藏”）

- [ ] **Phase 4: 多端覆盖与打包部署**
  - [ ] Windows 桌面端原生打包（轻量客户端 + 系统托盘）
  - [ ] 局域网 / 手机端 Web PWA 支持（HTTPS 自建证书或穿透）
